# Portal para Outra Dimensão

Projeto desenvolvido para a disciplina de **Desenvolvimento Web**, utilizando HTML, CSS e JavaScript.

## Sobre o projeto

O projeto consiste em uma página interativa que simula a descoberta e a entrada em um **portal para outra dimensão**.

O usuário pode investigar o portal, ativá-lo e atravessar para uma dimensão diferente. Após a entrada, é possível interagir com a página e descobrir diferentes destinos dentro dessa dimensão.

## Tecnologias utilizadas

* **HTML** — estrutura da página;
* **CSS** — estilização e efeitos visuais;
* **JavaScript** — interações e eventos da página.

## Funcionalidades

* Ativação do portal através de um botão;
* Alterações visuais após a interação;
* Transição para a dimensão púrpura;
* Eventos controlados por JavaScript;
* Interação para descobrir diferentes destinos;
* Uso de `document.getElementById()` para acessar e modificar elementos da página.

## Objetivo

Demonstrar, de forma criativa, a utilização do **JavaScript para realizar ações e eventos em uma página web**, utilizando o `document.getElementById()`.

## Desenvolvimento

Projeto desenvolvido como atividade avaliativa da disciplina de **Desenvolvimento Web**.
